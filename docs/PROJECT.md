# OctoSense — Project Definition

## Purpose

OctoSense demonstra como dados provenientes de tecnologias vestíveis podem
ser utilizados para acompanhar e compreender respostas do organismo humano.

## Core concept

Corpo humano -> sensor -> dado -> interpretação -> conhecimento.

## Initial scope

A primeira versão utilizará apenas dados sintéticos e reproduzíveis.

O projeto não realizará diagnóstico médico e não substituirá profissionais
ou equipamentos médicos.

## Evolution

1. Fundação do projeto.
2. Aplicativo com dados sintéticos.
3. Simulador determinístico.
4. API e persistência.
5. Containers e automação.
6. QA e DevSecOps.
7. Integração controlada com wearable.
8. Piloto real voluntário.
9. Recursos educacionais assistidos por IA.
10. Showcase público e distribuição da demonstração.
